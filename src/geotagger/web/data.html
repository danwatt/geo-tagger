Offline reference datasets used for reverse geocoding. Downloads pull from the public GeoNames / GeoFabrik / US Census servers and can take a while — the page keeps polling while a download runs, so it's safe to leave this tab and come back.

GeoNames (nearest-city lookup)

Cities, admin regions (state/county), and country names used as the fallback reverse-geocode when a photo falls outside every OSM place polygon below.

US Census places (incorporated places + CDPs)

The Census Bureau's national 1:500,000 place boundaries (~10 MB). Unlike OSM, this includes census designated places — the unincorporated suburbia that has no city boundary at all, so a photo there gets a real place name instead of whichever GeoNames town happens to be nearest. Consulted after OSM and before that nearest-city estimate.

Face matcher model

InsightFace's buffalo_l detection + recognition pack (~275 MB). Normally downloaded automatically the first time you scan for faces — pre-fetch it here instead if you'd rather not wait mid-scan.

OSM places (city / park / venue polygons)

Named place polygons from OpenStreetMap (via GeoFabrik state extracts), merged into one local database. Adding a state downloads its extract and appends its places to whatever's already there — safe to add states incrementally as your library grows.
