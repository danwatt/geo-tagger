Offline reference datasets used for reverse geocoding. Downloads pull from the public GeoNames / GeoFabrik / US Census servers and can take a while — the page keeps polling while a download runs, so it's safe to leave this tab and come back.

Backup

Downloads a compact JSON snapshot of the data nothing else can regenerate — places, people & families, face-to-person labels, per-photo lat/lng, and settings. Leaves out anything derivable by rescanning (photo metadata, reverse-geocode results, face embeddings, download history), so it's small even on a large library.

GeoNames (nearest-city lookup)

Cities, admin regions (state/county), and country names used as the fallback reverse-geocode when a photo falls outside every OSM place polygon below.

US Census places & ZIP areas

The Census Bureau's national 1:500,000 boundaries. Places include census designated places — the unincorporated suburbia that has no city boundary at all, so a photo there gets a real place name instead of whichever GeoNames town happens to be nearest. ZCTAs add each photo's ZIP code, and (via a small GeoNames crosswalk) the ZIP's mailing city as a last resort before that nearest-city estimate. ~90 MB total; rebuilds in seconds.

Face matcher model

InsightFace's buffalo_l detection + recognition pack (~275 MB). Normally downloaded automatically the first time you scan for faces — pre-fetch it here instead if you'd rather not wait mid-scan.

OSM places (city / park / venue polygons)

Named place polygons from OpenStreetMap (via GeoFabrik state extracts), merged into one local database. Adding a state downloads its extract and appends its places to whatever's already there — safe to add states incrementally as your library grows.

Street search (roads & lines)

Streets are not stored in any database — there are far too many of them to be worth it for reverse geocoding. Instead this searches the raw .osm.pbf downloads still sitting in the cache, live, and draws what it finds on the map below. Pan/zoom to the area you care about, type part of a street name or route number, and search: only roads passing through the visible map area are returned. If the raw downloads have been deleted, this stops working until a region is re-downloaded.
