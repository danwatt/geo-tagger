Offline reference datasets used for reverse geocoding. Both downloads pull from the public GeoNames / GeoFabrik servers and can take a while — the page keeps polling while a download runs, so it's safe to leave this tab and come back.

GeoNames (nearest-city lookup)

Cities, admin regions (state/county), and country names used as the fallback reverse-geocode when a photo falls outside every OSM place polygon below.

OSM places (city / park / venue polygons)

Named place polygons from OpenStreetMap (via GeoFabrik state extracts), merged into one local database. Adding a state downloads its extract and appends its places to whatever's already there — safe to add states incrementally as your library grows.
